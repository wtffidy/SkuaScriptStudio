# Potato artwork source backups

This folder preserves editable vector references for the Potato Studio theme.

- `potato-mascot-reference.svg` is the master mascot visual reference.
- Live Avalonia artwork is implemented in the parent folder in `PotatoMascotArtwork.axaml`, `PotatoTitleBarArtwork.axaml`, and `PotatoBackgroundArtwork.axaml`.
- Keep source references alongside the live XAML controls so artwork can be restored and refined without recreating it.
- Do not flatten the live artwork into a screenshot. Keep the client artwork scalable and cross-platform.
