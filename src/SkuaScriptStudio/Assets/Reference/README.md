# Potato artwork source backups

This folder contains editable SVG master references for the Potato Studio visual identity.

- `potato-mascot-reference.svg` — crowned potato character.
- `potato-patch-reference.svg` — potato family growing in the patch.
- `potato-titlebar-reference.svg` — wide plum-and-gold banner composition.
- `potato-background-reference.svg` — ambient workspace background treatment.

The live Avalonia controls are kept separately in the parent `Assets` folder:

- `PotatoMascotArtwork.axaml`
- `PotatoPatchArtwork.axaml`
- `PotatoTitleBarArtwork.axaml`
- `PotatoBackgroundArtwork.axaml`

Keep both representations. The SVGs are the editable visual source backups; the XAML files are the client implementation. Do not flatten the interface into a screenshot or remove the reference backups when changing the theme.
